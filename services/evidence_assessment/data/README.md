# 005I frozen offline assessment packet

`offline-v1.json` contains 19 agent-authored synthetic cases, search excerpts and structured model replies at reference time `2026-11-20T00:00:00+00:00`. These are **not** recorded Tavily results, actual Gemini assessments or independently reviewed human gold. Excerpts are short authored paraphrases attached to representative public source URLs. Quote validation checks those supplied fixture snippets; it does not establish that the authored wording is a verbatim quote on the linked page.

LF-normalized SHA-256: `77deb8d225124aca38d9fbd177056b798d8fad0124a112e702e3aae73c098e04`. The factory refuses changed bytes. The explicit authoring utility `tests/evidence_assessment/build_packet.py` is not run at startup or evaluation; changes require deliberate corpus review and a new pin. Expected outcomes/counts are fixed input annotations, not derived from observed pipeline results.

The packet covers incorrect/correct current officeholders, stable and incorrect historical facts, ambiguity, subjectivity, multiple claims, an unanswerable statement, missing/conflicting evidence, both provider timeouts, prompt injection, forged citations/quotes, invalid partial evidence, same-publisher/copy controls and model scope abstention. Only rows marked `demonstration` are used by the default offline UI; other statements return no simulated evidence. Core pipeline/provider code does not contain the target statement or its expected verdict.

The officeholder fixture was authored after inspecting the [Japanese Prime Minister's Office roster](https://japan.kantei.go.jp/105/meibo/daijin/index.html) and a [November 19 AP report](https://apnews.com/article/bdc0faac8244ea5ca145380636927f9b), which identify Takaichi Sanae/Sanae Takaichi as prime minister at the packet's reference date. The packet fixes that dated observation for reproducibility; it must not be presented as a current live lookup. Other representative URLs include the Royal Society of Chemistry, Britannica, NASA, Cornell and BirdLife. The deliberately conflicting/injected rows contain false or hostile authored content, explicitly for negative controls.

Repeated correct mock classifications establish transport, schema, scope, citation and failure behavior only. They cannot measure real Gemini semantic accuracy, source honesty, publisher independence or origin freshness. Live assessments use actual bounded Tavily results with no fixture fallback.
